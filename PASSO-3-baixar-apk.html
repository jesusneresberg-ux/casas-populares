📱 Passo 3: Baixar o APK

⏳ Atenção: O GitHub Actions demora 5-10 minutos para compilar o APK. Se você acabou de enviar o código, aguarde alguns minutos antes de baixar.
📊 Ver Progresso do Build:
Clique abaixo para acompanhar a compilação em tempo real:

👀 Ver Progresso (Actions)

🎯 Escolha uma opção para baixar:

✅ Opção 1: Via Actions (Artifacts) - Recomendado

  1. Clique no botão abaixo para abrir GitHub Actions
  2. Clique no workflow mais recente (primeiro da lista)
  3. Role a página para baixo até encontrar "Artifacts"
  4. Clique em casas-populares-debug.apk para baixar
📦 Abrir GitHub Actions
📸 Como vai aparecer: 
Actions
  └─ Build Android APK ✅ (verde = pronto)
       └─ [CLIQUE AQUI no workflow]
            └─ Role para baixo ⬇️
                 └─ Artifacts
                      └─ 📦 casas-populares-debug.apk [BAIXE AQUI]

🚀 Opção 2: Via Releases (Mais Simples)

  1. Clique no botão abaixo
  2. Clique na release mais recente
  3. Em "Assets", baixe app-debug.apk
🎁 Abrir Releases

📲 Como instalar no celular Android:

  1. Transfira o arquivo .apk para o seu celular Android
  2. No celular, abra o arquivo .apk
  3. Se solicitar, permita "Instalar de fontes desconhecidas"
  4. Clique em "Instalar"
  5. Pronto! O app estará instalado 🎉

⚠️ Problemas?

  • Workflow não aparece? → Aguarde 1-2 minutos após o push
  • Build falhou (vermelho)? → Clique no workflow para ver o erro nos logs
  • Sem Artifacts? → Aguarde o build terminar (ícone verde ✅)
  • Releases vazio? → Use a Opção 1 (Actions/Artifacts)
🔄 Gerar novo APK:
Sempre que fizer alterações no código: 
git add .
git commit -m "Suas alterações"
git push
O GitHub gera um novo APK automaticamente!
