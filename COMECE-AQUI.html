🚀 Gerar APK Automaticamente

Siga os 3 passos abaixo para ter seu app Android pronto!

1

Criar Repositório no GitHub

Crie um novo repositório no GitHub para hospedar o código do app. Não se preocupe, é rápido e simples!

📦 Abrir Passo 1 ⏱️ 2 minutos
2

Enviar Código para o GitHub

Execute um script simples que vai enviar todo o código para o GitHub. O GitHub Actions vai começar a compilar automaticamente!

⚠️ Execute este arquivo direto na pasta do projeto (duplo-clique)

📁 casas-populares\PASSO-2-enviar-codigo.bat

⏱️ 1 minuto
3

Baixar o APK

Aguarde o GitHub compilar (5-10 minutos) e baixe seu APK pronto para instalar no Android!

📱 Abrir Passo 3 ⏱️ 5-10 minutos (compilação automática)
💡 O que vai acontecer:
  1. Você cria um repositório vazio no GitHub
  2. Envia o código do app para lá
  3. O GitHub Actions compila automaticamente e gera o APK
  4. Você baixa e instala no seu celular Android
